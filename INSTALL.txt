右键小工具 2.1（测试版）

适用：Apple 芯片 Mac。最低构建目标 macOS 13，实际验证环境 macOS 26.7。

1. 保留此文件夹中的文件在一起，无需解压里面的“右键小工具.app.zip”。
2. 双击“安装或更新.command”，安装到个人“应用程序”目录。
3. 在工具窗口打开 Finder 扩展设置并启用“右键小工具”。
4. 打开普通文件夹，右键选择新建文件、在此处打开终端或打开活动监视器。

当前使用临时签名，未做 Apple Developer ID 签名和公证。互联网下载后的首次安装可能被系统阻止，目前尚未完成其他电脑的首次安装验证。请核实来源；本包不包含关闭系统安全检查的步骤。

已有同名文件会自动编号。应用升级会备份旧版本。停用时在系统设置中关闭 Finder 扩展，再退出主程序。
