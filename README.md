# 右键小工具 / Mac Right Click

一个使用 Swift 和 macOS Finder 扩展制作的轻量右键工具。

## 功能

- **新建文件 →** TXT、Word、PowerPoint、Excel、Markdown、Python、JSON、自定义文件名。
- 选择类型后立即创建；同名文件自动编号，不覆盖原文件。
- Office 文档使用有效的空白模板；PowerPoint 含一张空白幻灯片，Excel 含一个空白工作表。
- **在此处打开终端**：打开当前或所选文件夹的系统终端。
- **打开活动监视器**：打开或激活 macOS 活动监视器。

在文件夹空白处右键时使用当前文件夹；右键文件夹时使用该文件夹；右键文件时使用文件所在文件夹。功能作用于 Finder 实际目录和桌面。只读位置和文件夹访问仍受系统权限限制。

## 当前状态与要求

- 版本：2.1，公开测试版本。
- 当前构建仅支持 **Apple 芯片 Mac（arm64）**。
- 最低构建目标为 macOS 13；实际功能验证环境为 macOS 26.7。更早系统尚未实测。
- 使用本机临时签名，**未做 Apple Developer ID 签名和公证**。从互联网下载到其他电脑后，macOS 可能阻止打开；尚未完成陌生电脑的首次下载、安装和重启测试。

## 下载与安装

1. 在本仓库右侧进入 **Releases**，下载安装附件 `mac-right-click-v2.1-macos-arm64.zip`。GitHub 自动提供的 `Source code` ZIP 是源码。
2. 解压安装附件，双击其中的 `安装或更新.command`。
3. 安装到个人应用程序目录：`~/Applications/右键小工具.app`。更新前会保存旧版本备份。
4. 在工具窗口点击 **打开 Finder 扩展设置**，启用“右键小工具”。
5. 在普通 Finder 文件夹的空白处右键测试。

如果系统阻止运行，请先核实软件来源。当前版本更适合愿意自行构建和测试的用户；没有提供关闭系统安全检查的安装方式。

关闭设置窗口不影响右键功能。退出主程序后，下次菜单操作可自动唤起；无需手动保持窗口打开。扩展开启状态通常会由系统保留，但重启后恢复行为尚未实测。

## 从源码构建

需要 Apple 芯片 Mac、Apple Command Line Tools 和 Python 3.9 或更高版本。不需要安装第三方 Python 库；Office 模板已包含在仓库中。

在仓库目录执行：

```sh
python3 build.py
```

生成的应用位于 `Build/右键小工具.app`。

运行回归测试：

```sh
zsh test.command
```

生成与 Releases 配套的安装包：

```sh
python3 package_release.py
```

安装包会生成在 `dist/`。`install.command` 必须与配套的 App ZIP 放在一起，直接从源码目录运行它不会安装应用。

## 项目结构

- `Source/`：主程序、Finder 扩展、文件创建和动作传递代码。
- `Templates/`：空白 Office 模板。
- `Tests/`：重名保护、中文路径、Office 模板、并发创建等测试。
- `build.py`：本机构建与临时签名。
- `package_release.py`：生成下载附件，不上传任何内容。
- `install.command`：安装与更新脚本。

## 操作记录

工具只使用本机文件和系统应用接口，不联网。操作路径、耗时和错误会写入本机日志，用于故障排查。可以从工具窗口打开日志目录；日志超过约 1 MB 时重置。反馈问题前请移除日志中的个人路径。

## 停用

在系统设置中关闭本工具的 Finder 扩展，再退出主程序。卸载时移除个人应用程序目录中的 App；此前创建的文件不会被改动。
